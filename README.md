# 🐟 Koi Fish Pet

A tiny koi that swims around your browser tabs.

- **Click it** to change its colour (a new colour every time)
- **Grab and drag it**, and it escapes and hides for a few seconds
- **Pester it too much** and it sulks off-screen for longer
- Hovers, makes ripples, glows and darts away when startled

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser.
2. Click this link: [Install Koi Fish Pet](https://raw.githubusercontent.com/minaduddin/Koi-Fish-Pet/main/koi-fish-pet.user.js)
3. Click **Install** in Tampermonkey.
4. Open or refresh any website and the koi appears.

It updates automatically when a new version is released.

## Privacy

No data is collected or sent anywhere. The only thing saved is the fish's colour, stored locally by Tampermonkey.
